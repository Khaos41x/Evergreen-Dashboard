# Ativos nativos Evergreen

`logo.png` é uma cópia byte a byte de `public/evergreen-symbol.png`, árvore original fornecida pelo usuário. Nenhum redesenho, filtro ou recoloração foi aplicado a esse arquivo.

`npm run mobile:assets` usa a ferramenta oficial `@capacitor/assets` para escala/composição exigida pelos ícones e splash Android/iOS, com fundo `#f3f4f2` já existente na identidade. Os ativos originais de autenticação em `public/` permanecem intactos. Não há imagens geradas por IA.
